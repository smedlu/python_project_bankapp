# BankApp

## Описание
Приложение для маскировки конфиденциальных данных (номеров карт и счетов), а также фильтрации и сортировки банковских операций.

## Функциональность
- Маскировка номеров карт в формате `XXXX XX** **** XXXX`
- Маскировка номеров счетов в формате `**XXXX`
- Фильтрация транзакций по статусу (например, `EXECUTED`)
- Сортировка операций по дате (от новых к старым)
